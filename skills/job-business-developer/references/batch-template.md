# Batch file template

`outreach/<YYYY-MM-DD>-batch.md`

```markdown
# Outreach batch — <date> (week <yyyy>-W<nn>)

**Status:** drafts, nothing sent. Approve by number: "send 1, 3; edit 2: <change>; skip 4".

## Follow-ups due
| # | Person | Sent | Original ask | Follow-up draft |

## Referral asks (active applications)
### <n>. <Person> · <company> · <channel>
- **Why them:** tie band, score, shared detail, MASTER ids behind any claim
- **Ask:** <one line>
- **Draft:**
  > <≤120 words>

## Warm reconnects
(same block per person)

## Agency registrations
### <n>. <Agency> · <portal URL>
- **Fields:** headline, skills, availability, location, work type, rate (if asked)
- **Upload:** contracts/base-resume/resume.pdf
- **Recruiter note (if a name is known):**
  > <60–90 words>

## Open questions for the candidate
- <anything the drafts need that isn't in MASTER>
```
